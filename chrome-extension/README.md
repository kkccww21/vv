# KVideo DLNA Cast 扩展

这个Chrome扩展允许您将视频直接投屏到支持DLNA/UPnP的设备（如投影仪、智能电视等）上。

## 安装步骤

1. 打开Chrome浏览器，访问 `chrome://extensions/`
2. 在右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录 (`chrome-extension`)
5. 扩展安装完成！

## 使用说明

### 自动扫描添加设备（推荐）

1. 点击浏览器工具栏中的扩展图标
2. 点击「扫描设备」按钮
3. 扩展会自动扫描局域网内的DLNA设备
4. 扫描完成后，发现的设备会自动添加到列表中

### 手动添加DLNA设备

如果自动扫描没找到您的设备：

1. 点击浏览器工具栏中的扩展图标
2. 点击「手动添加设备」
3. 填写设备信息：
   - 设备名称：例如「坚果投影仪」
   - 控制URL：留空的话，输入IP后会自动尝试坚果投影仪的默认配置
   - 服务类型：通常是 `urn:schemas-upnp-org:service:AVTransport:1`

### 如何找到设备的控制URL？

如果您有Python脚本已经能正常工作，可以参考其中的配置。对于常见设备：
- 坚果投影仪：`http://<IP>:49152/_urn:schemas-upnp-org:service:AVTransport_control`
- 当贝投影：`http://<IP>:46577/upnp/dev/<UUID>/svc/upnp-org/AVTransport/action`

### 投屏视频

1. 在KVideo播放页面，播放您想投屏的视频
2. 点击播放器控制栏中的DLNA图标（Wi-Fi信号样式）
3. 在弹出的设备列表中选择您的设备（或点击「扫描局域网设备」）
4. 视频将开始在设备上播放！

## 注意事项

- 确保您的电脑和投屏设备在同一局域网内
- 某些视频源可能需要代理才能正常投屏
- 首次使用建议先用Python脚本测试设备是否可用
- 扫描时会优先检查192.168.3.x网段（坚果投影仪常用网段）

## 故障排除

如果投屏失败，请检查：
1. 设备是否已开机并连接到同一网络
2. 控制URL是否正确（可先用Python脚本验证）
3. 视频源是否可以被设备访问
4. 如果自动扫描失败，可以尝试手动添加设备
